# Project Statement

## Problem Statement

Security logs contain information about login activities. When many login attempts are present, repeated failed attempts can be difficult to notice manually.

This project provides a simple way to check sample security logs and identify activities that may need attention.

## Scope of the Project

The project is limited to basic login log monitoring. It checks sample logs, counts failed login attempts, detects repeated failures and identifies unknown users.

It is an educational project and does not monitor a real computer or network.

## Target Users

- Beginner Python students
- Students learning basic cybersecurity concepts
- Students learning about security logs

## High-Level Features

- Read sample security logs
- Check login status
- Count failed attempts
- Detect repeated failed attempts
- Detect unknown users
- Display a security alert
- Save a simple report
